# 委員 E（務實的隊長）— phase2-review 一輪

## 1. 結果說明什麼
- **站得住的是結構，不是分數**：不死保底（`mission.py:376-396` try/finally）、飛行記錄欄位（R4）、「速度猜對時校正零影響」（README:128、四世界表）。這三樣在任何速度下都不吃虧，上機第一小時都用得到。
- **假模型產物**：「27→75 分、Goal 10/20→20/20」建立在「真速 0.05」這個沒人量過的情境（README:128）。校正的四個門檻（0.8、≥1 m、20 s、0.5；`mission.py:101-109`）是對著假機器人的 3 s 起停與 20°/s 調出來的，三次失敗紀錄本身就在說這件事（Basic Memory「速度校正的三次失敗」）。
- 「刪點最不後悔」只有在刪點真的觸發時才有意義；真速 ≥0.1 時可能從不觸發（ros/README:48 自己也這樣寫）。
- 97 個測試守的是回歸，不證明模型對。

## 2. 值得做的最多三件
1. **向主辦／POC 提問**（`rules.md:9` 提問截止 2027-01-20 12:00）：Goal 是否需全點（A/B）、逾時是否保留已得分（T0/T1）、分數表（README:108 說不在 PDF）、相機座標與 offset。
   - 驗收：問題清單成文並送出，記下回覆或「無回覆」。
   - 不做的代價：第 3、4 場探針（ros/README:46-52）要花掉第一小時 5–7 場中的 2 場。有官方答案就能把這 2 場換成校準。
2. **拿掉 `survey()` 的 2 秒阻塞**（`user_node.py:238-244, 392`）：它在 `run_mission` 的 try/finally 之外，而且用 `rospy.sleep`。
   - 後果一：`_Run.t0` 在 survey 之後才設（`mission.py:156`），每場少算 2 s。
   - 後果二：`/clock` 停住時，`mission_finish` 永遠不會被呼叫。
   - 做法：只在 `survey_only` 時阻塞，平常場次改成被動累積 `_nav_count` 並在 log 印出。
   - 驗收：假機器人測試 start 到 `mission_start` 之間 < 0.5 s；`survey_only` 路徑仍有輸出。
3. **逐項核對 ROS 名稱與欄位**：把 `user_node.py:22-34` 的 import 與欄位（`CtlCommandGoal.target/type`、`result.success/message`、`CtlStatus.type.type`）對照 manual.txt 1413-1487、1930-1952 列成表。
   - 驗收：表中每格有行號。
   - 不做的代價：一個 ImportError 就是一次重建加重啟。我認為損失有限（約半小時），所以只給 ≤ 2 小時。

其餘（調參、vision、文件）**該停**，與 R6 一致。

## 3. 上機前該懷疑或降級
- **相機修正**（`mission.py:349-353`）：`settled` 被無條件換成修正後的結果，而 `should_notify` 需要 `level>0`（:357）。修正方向或座標系錯，Lv1+ 可能變 Lv0，不回報，白丟分。
  - 座標系沒驗：手冊 1199-1200 說要用相機安裝姿態另做轉換；`vision.py` 只處理 0.14 m 位移（rotation 未驗證）；影像 encoding 也沒驗（`user_node.py:57`）。
  - 增益是 fake-sensitive（README:130）。
  - 不必拆程式：`camera_fix_max_m=0` 時所有修正量都被「too large」擋掉（:336），自動退回 `self.move(cp,1)`。預設設 0，第 2 場 log 驗過座標再開。
- **校正門檻**：真機器人起停若不是 3 s，`slowdown>1.25` 可能誤觸發，把正常速度調慢，反而增加刪點。夾限 0.5 倍限制了傷害，但「猜對零損失」只在假起停下成立。第 2 場要先看 `leg:` 行再信任。
- **探針旗標**：預設關有測試守住，可留。若問題 1 有答案，就不需要開。決賽前必須剝除（規則書 4.2.4，council synthesis 共識 5）。
- **`kibo.tune` 的九個變體**：除「不校正速度」「不刪點」外都是噪音（README:132）。不要再拿它做決策，也不必刪。

## 4. 使用者回來後第一件決定
**把問題 1 的提問清單批准並送出（或指定誰送）**。只有隊伍能問，它不需要模擬器，而且能省下 2 場探針。同時決定：R1–R6 從 `open` 改 `accepted`，並宣告 `src/` 在拿到 `cheat_sheet.json` 之前凍結。
